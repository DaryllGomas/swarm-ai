# Code of conduct

1. **Argue about ideas, not people.** Disagree about plans, code and priorities. Don't attack contributors,
   reviewers, projects or the people behind them.
2. **Assume good faith**, and act in good faith.
3. **Be honest.** Cite what you claim, and say when something is a guess or written by AI. Never invent a
   source, statistic or quote.
4. **Protect people.** No private information and no targeting anyone. Work Swarm routes is for the public
   good; it is never a way to go after a person.
5. **Respect the system.** Don't game the votes, the scheduler or the review queue. Don't try to slip
   instructions to other people's AI agents through task text, issues or pull requests.

Breaking these leads to content removal and, for repeat or serious cases, a block and a revoked contributor
key. To raise a concern, open an issue. If it involves someone's safety or private information, report it
privately with **Security → Report a vulnerability** instead.
